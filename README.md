# 🚆 Train Consist Management App

## 📌 Overview
The **Train Consist Management App** is a console-based Java application that simulates how a railway system manages a train’s consist — the sequence of bogies attached to an engine.

This project demonstrates how **Core Java and Data Structures** are applied to solve real-world railway operational problems.

---

## 🎯 Objectives
- Apply data structures in real-world scenarios
- Build modular, scalable system design
- Enforce business rules and safety constraints
- Transition from procedural to declarative programming

---

## 🚂 Features
- Manage passenger and goods bogies
- Track train composition and ordering
- Prevent duplicate or invalid configurations
- Map bogies to capacity
- Perform sorting, filtering, grouping, and aggregation
- Validate input formats using Regex
- Enforce real-world safety rules

---

## 🧠 Learning Approach
Each use case introduces one new concept while reinforcing previous ones.

Focus areas:
- Why a data structure is used
- What problem it solves
- How system evolves step-by-step

## 🚀 How to Run

1. Clone the repository:
```bash

```

2. Open in IntelliJ IDEA

3. Navigate to:
```
src/main/
```

4. Run any use case:
