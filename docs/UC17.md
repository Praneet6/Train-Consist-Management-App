## UC17: Sort Bogie Names Using Arrays.sort()

### Description
This use case demonstrates how to sort bogie names alphabetically using Java’s built-in `Arrays.sort()` method instead of manual sorting algorithms.

### Goal
Use optimized library methods to perform sorting efficiently and cleanly.

### Concepts Used
- Arrays.sort()
- Natural Ordering (Alphabetical sorting)
- Built-in Algorithms
- Time Complexity O(n log n)
- Clean Code Practices

### Flow
1. Create an array of bogie names.
2. Display original order.
3. Apply `Arrays.sort()`.
4. Display sorted result.
