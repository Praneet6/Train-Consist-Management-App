# UC11: Validate Train ID & Cargo Codes (Regex)

## Objective
Validate Train ID and Cargo Code formats using Regular Expressions in Java.

---

## Concepts Used
- Regex (Regular Expressions)
- Pattern class
- Matcher class
- matches() method
- Input validation
- Data integrity enforcement

---

## Problem Statement
Previous use cases assumed that all train data entered was valid.  
In real railway systems, invalid Train IDs or Cargo Codes can cause:

- Incorrect records
- Failed downstream processing
- Unreliable reports

Example:

✔ Valid Train ID: `TRN-1234`  
❌ Invalid Train ID: `TRAIN12`, `TRN12A`, `1234-TRN`

✔ Valid Cargo Code: `PET-AB`  
❌ Invalid Cargo Code: `PET-ab`, `PET123`

---

## Validation Rules

### Train ID Format:
TRN-1234

Pattern:
```java
TRN-\\d{4}
```
