# UC2 - Add Passenger Bogies to Train

## Objective
Enable dynamic addition, removal, and validation of passenger bogies.

## Operations Performed
- Add bogies (Sleeper, AC Chair, First Class)
- Remove a bogie (AC Chair)
- Check existence using contains()

## Data Structure Used
- ArrayList

## Concepts Covered
- add()
- remove()
- contains()
- CRUD Operations

## Output
[Sleeper, First Class]

## Outcome
Simulates real-world bogie management with dynamic list operations.
