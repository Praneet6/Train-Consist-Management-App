# UC6 - Map Bogie to Capacity

## Objective
Associate bogies with their capacity using key-value mapping.

## Problem in UC5
Set stores only values → cannot attach attributes.

## Solution
Use HashMap to map bogie → capacity.

## Concepts Used
- Map Interface
- HashMap
- put()
- entrySet()
- Key-Value mapping

## Outcome
Each bogie is linked to its seating or load capacity.
