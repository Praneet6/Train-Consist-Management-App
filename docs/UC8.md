# UC8 - Filter Passenger Bogies Using Streams

## Objective
Filter bogies based on seating capacity using Stream API.

## Problem in UC7
Sorting organizes data but cannot filter based on conditions.

## Solution
Use Stream API with filter().

## Concepts Used
- stream()
- filter()
- lambda expressions
- collect()

## Example
Condition:
b.capacity > 60

## Output
Sleeper -> 72
General -> 90

## Outcome
Only high-capacity bogies are selected.
