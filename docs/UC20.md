## UC20: Exception Handling During Search Operations

### Description
This use case ensures that search operations are only performed when bogies exist in the train. It prevents invalid execution using fail-fast validation.

### Goal
Stop search operations early if the train consist is empty.

### Concepts Used
- Defensive Programming
- IllegalStateException
- Fail-Fast Principle
- Runtime Exception Handling
- State Validation

### Flow
1. User initiates search.
2. System checks if bogie collection is empty.
3. If empty → throw IllegalStateException.
4. Catch exception and display message.
5. If valid → perform search normally.
