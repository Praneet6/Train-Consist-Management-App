## UC18: Linear Search for Bogie ID

### Description
This use case demonstrates how to search for a specific bogie ID in an unsorted array using Linear Search.

### Goal
Identify whether a bogie exists in the train consist using sequential traversal.

### Concepts Used
- Linear Search
- Sequential Traversal
- equals() method for String comparison
- Early termination (break)
- Time Complexity O(n)

### Flow
1. Create an array of bogie IDs.
2. Provide a search key.
3. Traverse array sequentially.
4. Compare each element with the search key.
5. Stop when found or complete traversal.
6. Display result.
