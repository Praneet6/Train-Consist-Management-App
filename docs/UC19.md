## UC19: Binary Search for Bogie ID

### Description
This use case demonstrates how to efficiently search for a bogie ID using Binary Search on a sorted dataset.

### Goal
Improve search performance by reducing the search space using divide-and-conquer.

### Concepts Used
- Binary Search
- Divide and Conquer
- compareTo() for String comparison
- Index-based traversal (low, high, mid)
- Time Complexity O(log n)

### Flow
1. Ensure bogie IDs are sorted.
2. Initialize low and high indexes.
3. Find mid index.
4. Compare search key with mid element.
5. Adjust search range.
6. Repeat until found or exhausted.
7. Display result.
