# UC1 - Initialize Train and Display Consist Summary

## Objective
Initialize the train consist and display its initial state.

## Description
This use case sets up the application and creates an empty train consist using a dynamic data structure.

## Data Structure Used
- ArrayList (dynamic resizing)

## Concepts Covered
- Class and Main Method
- List Interface
- ArrayList
- Console Output

## Output
Initial Bogie Count: 0  
Current Train Consist: []

## Outcome
Provides the foundation for further operations like adding/removing bogies.
