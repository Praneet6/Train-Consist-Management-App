## UC16: Sort Passenger Bogies by Capacity (Bubble Sort)

### 🔴 Drawback of UC15 Approach
In UC15, cargo safety is handled properly, but data organization for reporting is still not addressed.

Earlier use cases relied on:
- Comparator
- Streams
- Built-in sorting methods

However:
- ❌ Internal sorting logic is hidden
- ❌ Students don’t understand how sorting works
- ❌ Debugging and optimization become difficult

To build strong fundamentals, we implement **manual sorting using Bubble Sort**.

---

### 🎯 Goal
Sort passenger bogie capacities using a **basic algorithm (Bubble Sort)** without using library methods.

---

### 👤 Actor
User

---

### 🔄 Flow
1. User provides bogie capacities
2. System iterates through the array
3. Adjacent elements are compared
4. If out of order → values are swapped
5. Multiple passes are executed
6. Sorted array is displayed

---

### 🧠 Key Concepts Used
- **Bubble Sort Algorithm** – Repeated comparison and swapping
- **Array Manipulation** – Direct index-based access
- **Nested Loops** – Multiple passes over data
- **Swapping Logic** – Exchange elements using temp variable
- **Algorithmic Thinking** – Understanding internal working
- **Time Complexity (O(n²))** – Performance awareness

---

### 📌 Key Requirements
- Create an array of capacities
- Use nested loops
- Compare adjacent values
- Swap when needed
- Display sorted output
- Do NOT use `Arrays.sort()` or `Collections.sort()`

---

### ✅ Key Benefits
- Builds strong algorithm foundation
- Improves logical thinking
- Helps in debugging and optimization
- Bridges theory and implementation

---
