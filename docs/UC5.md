# UC5 - Preserve Insertion Order of Bogies

## Objective
Maintain insertion order while ensuring uniqueness.

## Problem in UC4
LinkedList preserves order but allows duplicates.

## Solution
Use LinkedHashSet to combine:
- Order preservation
- Duplicate prevention

## Concepts Used
- Set Interface
- LinkedHashSet
- add()
- Ordered iteration

## Outcome
Train formation remains ordered and duplicate-free.
